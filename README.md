# Bradens3dHeadGenerator

Minecraft skin renderer for generating 3D head and full-body renders.

This project is built to be used alongside [BradensSkinProxy](https://github.com/BradenM64/BradensSkinProxy).

By default, the frontend expects the skin proxy API to run at:

```text
http://localhost:3000
```

## Configuration

Frontend settings are stored in:

```text
config.json
```

The configuration contains the skin proxy API URL, control ranges, and default rendering settings.
